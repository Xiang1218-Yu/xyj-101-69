## 1. 产品概述

「故事星球」是一个让家长为孩子创作专属绘本的在线平台。家长只需输入孩子的名字、喜欢的动物和最近经历的事，系统便会生成一本以孩子为主角的温暖绘本故事，配以可爱插画风格，支持中英双语，并可将绘本导出为PDF下载保存。

- **目标用户**：3-10岁孩子的家长，希望用个性化故事激发孩子阅读兴趣
- **核心价值**：让每个孩子成为故事的主角，用专属绘本记录成长瞬间

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 家长用户 | 无需注册，直接使用 | 输入信息、生成绘本、预览阅读、导出PDF |

### 2.2 功能模块

1. **首页**：品牌展示、产品介绍、开始创作入口
2. **引导输入页**：分步骤收集孩子信息（名字、动物、经历、语言偏好）
3. **生成等待页**：故事生成过程中的沉浸式等待动画
4. **绘本阅读页**：翻页式绘本浏览、PDF导出下载

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 首页 | 英雄区 | 品牌标语、星球主题动画背景、开始创作按钮 |
| 首页 | 特色介绍 | 展示3个核心特色：专属故事、温暖插画、中英双语 |
| 首页 | 作品展示 | 展示示例绘本封面，激发创作欲望 |
| 引导输入页 | 步骤一：孩子名字 | 输入孩子的名字，实时预览在故事中的效果 |
| 引导输入页 | 步骤二：喜欢动物 | 从动物列表选择或自由输入喜欢的动物 |
| 引导输入页 | 步骤三：最近经历 | 输入或选择孩子最近经历的事（如上学、旅行、交朋友等） |
| 引导输入页 | 步骤四：语言选择 | 选择中文或英文生成绘本 |
| 生成等待页 | 加载动画 | 星球旋转、星星飘散的沉浸式等待体验 |
| 生成等待页 | 进度提示 | 显示当前生成阶段（构思故事→绘制插画→装订成书） |
| 绘本阅读页 | 绘本翻页 | 左右翻页浏览完整绘本，每页包含插画和文字 |
| 绘本阅读页 | 页码导航 | 显示当前页码/总页码，支持快速跳页 |
| 绘本阅读页 | PDF导出 | 一键导出绘本为PDF文件下载 |

## 3. 核心流程

用户打开故事星球首页 → 点击「开始创作」→ 进入分步引导页面 → 依次输入孩子名字、选择动物、填写经历、选择语言 → 点击「生成我的绘本」→ 进入生成等待页面（展示沉浸式动画）→ 生成完成后自动跳转绘本阅读页 → 翻页浏览绘本 → 可导出PDF下载

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：温暖的奶油黄（#FFF8E7）作为背景，搭配珊瑚橙（#FF6B6B）作为强调色
- **辅助色**：薄荷绿（#7EC8A4）、天空蓝（#87CEEB）、薰衣草紫（#C4A8FF）
- **按钮风格**：大圆角（rounded-2xl），柔和阴影，hover时微微上浮
- **字体**：标题使用温暖手写风格字体，正文使用圆润可爱的无衬线字体
- **布局风格**：卡片式布局，大量留白，营造轻松阅读感
- **插画/图标风格**：圆润可爱、线条柔和的绘本插画风格，配合星星、星球等宇宙元素

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 首页 | 英雄区 | 星球动画背景、大标题手写体、珊瑚橙CTA按钮、星星装饰 |
| 首页 | 特色介绍 | 三张圆角卡片、图标+文字、浅色渐变背景 |
| 首页 | 作品展示 | 横向滚动的绘本封面卡片、圆角阴影 |
| 引导输入页 | 进度条 | 顶部步骤指示器（1-2-3-4）、当前步骤高亮、已完成步骤打勾 |
| 引导输入页 | 输入区 | 大输入框、圆角、柔和边框、动物选择卡片网格 |
| 引导输入页 | 导航按钮 | 下一步/上一步圆角按钮、珊瑚橙主按钮、灰色次按钮 |
| 生成等待页 | 动画区 | 中央星球旋转、周围星星粒子飘散、渐变深蓝背景 |
| 生成等待页 | 文字提示 | 当前阶段文字、进度条动画 |
| 绘本阅读页 | 绘本展示 | 中央绘本卡片、翻页动画、左右箭头导航 |
| 绘本阅读页 | 工具栏 | 底部工具栏：页码、导出PDF按钮、返回按钮 |

### 4.3 响应式设计

- 桌面优先设计，绘本阅读区域在桌面端展示最佳
- 平板端：绘本卡片自适应缩放，保持阅读体验
- 移动端：输入页改为纵向排列，绘本阅读改为上下滑动翻页

### 4.4 设计特色

- 星球主题贯穿全站，首页有浮动的星球和星星装饰
- 输入引导页使用步骤卡片式设计，每步配有可爱的小图标
- 生成等待页使用宇宙星空主题的沉浸式动画
- 绘本阅读页模拟真实翻书效果，插画占主体，文字在下方
- 整体色调温暖明亮，传递安全感和温馨感
